# 雾境远征 · 地图战斗 Demo

一款在浏览器运行的单机战术远征游戏。Mixar 制作可编辑资产和 GLB，Three.js 绘制实时地图、编队与战斗，React 提供剧情、操作和编辑器。存档保存在本机浏览器，游玩无需游戏服务器或 API Key。

现已接入独立剧情战役 **《山河初燃》**：以用户指定的故事骨架与《星火燎原》第一、二卷为参考，串联 **1927 年秋收起义至 1930 年秋罗坊会议，6 章 20 关**。从首页点击「进入《山河初燃》」。原有三据点远征及其工坊、存档继续保留。

## 启动与验证

开发与构建使用 Node.js 20.19+ 或 22.12+。运行全部浏览器测试和复拍工具请使用 Node.js 22.18+（直接读取战斗核心的 TypeScript 文件），并安装 Google Chrome。

```sh
cd living-world-web
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。端口被占用时会明确报错，不会自动换端口，避免切到不同浏览器存档。七日危机使用独立的 5174 端口。

```sh
npm test          # 战斗核心、配置与存档测试
npm run build    # TypeScript 检查 + 生产包 dist/
npm run preview  # 预览生产包
npm run test:e2e  # 浏览器全流程测试，需要本机 Google Chrome 和运行中的开发服务
npm run test:battle-ui # 战斗演出、暂停续播、目标指向与满编布局专项验证
npm run test:map-ui    # 实际加载 GLB、三维行军、手机布局与图形中断回退
npm run test:story-ui  # 剧情20关/全部节点、选择、战斗入口、存档恢复、剧本导出与手机布局
```

若开发服务不在默认端口：

```sh
GAME_URL=http://127.0.0.1:5183 npm run test:e2e
```

浏览器测试使用隔离浏览器上下文，不修改你日常浏览器的存档。覆盖标题页、剧情、地图移动、编队、两条局部路线、战斗回放、胜利解锁、刷新恢复、三个编辑器、非法数据提示和取消草稿。截图输出到 `e2e/`，已从 Vite 监听中排除。

## 三维工坊与 Mixar 制作流程

打开标题画面右上角「菜单 → 三维工坊」。[模型校样](http://127.0.0.1:5173/?lab=assets) 可以并排检查灰模和游戏模型，切换四个固定机位和线框，拖动旋转、滚轮缩放。复制校样链接会保存当前视角。[关卡布景](http://127.0.0.1:5173/?lab=map&level=s03) 支持选择全部 20 关和节点。[动作分镜](http://127.0.0.1:5173/?lab=battle&frame=8&pose=.36) 可指定事件和动作百分比。工坊使用独立的固定队伍和地图状态。

1. 在 Mixar 打开[原生工程](public/atelier/source/field-kit.mixar)。左侧陈列九件成品，右侧陈列对应灰模。在资产根节点下选择部件进行编辑。角色的 `arm_l`、`arm_r` 是动作枢轴，`faction_cloth` 控制阵营色。另提供 [.blend 工程](public/atelier/source/field-kit.blend) 和[生成脚本](tools/art/build_field_kit.py)。
2. 保存后在本目录运行 `npm run art:export -- --asset house` 更新民居。可用 `--source 路径` 指定另存的工程。[资产清单](public/atelier/manifest.json) 提供全部资产 ID、尺寸、面数、材质和制作工具版本。当前导出器支持网格、修改器及平涂材质参数，使用自定义贴图需要扩展导出器。
3. 刷新同一校样网址检查效果。下面的复拍命令会保存 PNG、文件指纹、动作和镜头参数，以及版本对照网页。浏览器版本或图形后端不同可能出现像素差异。
4. 从脚本重新生成整套资产可运行 `npm run art:build -- --out .local/rebuilt-kit`。默认输出目录为 `public/atelier`，全量重建会覆盖其中的同名工程和模型。需要保留手工编辑时请使用单件回导。

```sh
npm run test:atelier
npm run review:3d -- --out .local/reviews/pass-02 --baseline public/atelier/reviews/field-v1
```

[首轮与定稿的实拍对照](http://127.0.0.1:5173/atelier/reviews/field-v1/index.html) 包含九个模型、民居线框、三种关卡地形和四个战斗动作时刻。当前工作区在 `.local/authoring/` 保留实际使用的 Mixar 4.4.7。其他机器可安装[官方 Mixar](https://github.com/Mixar-AI/mixar-app/releases/tag/v4.4.7)，用 `MIXAR_BIN` 指定可执行程序。游玩只需浏览器和已导出的网页资源。

## 《山河初燃》剧情战役

地图左上角切换章节或地点，底部行动栏执行当前命令。「行程详情」可查看任务、史实与来源，右上角「行军菜单」可打开手记、剧本、章节地图和返回标题。在手机上也可以直接点选地图上的地点。

进入章节地图后，选择已开放的关卡并启程。关卡先播放背景与开场对白，再进入独立节点地图。点击地图地点查看描述，通过「前往选中节点」沿相连道路行走；当前位置的行动完成后才能继续。可选支线允许回头，出口要求本关所有主线目标完成。结束本关的收束对白后，下一关才会开放。

| 章 | 关卡 | 叙事重点 |
| --- | --- | --- |
| 秋收余火 | 秋收、文家市、芦溪、三湾 | 起义受挫、转兵、伤员撤收与基层组织重建 |
| 山中立足 | 古城与茅坪、茨坪 | 地方合作、军民关系、生活与纪律 |
| 会师与风雨 | 砻市、龙源口、湘南、黄洋界 | 会师、根据地发展、八月失败与山口防守 |
| 风雪赣南 | 柏露、大余、大柏地、东固 | 留守与远行、风雪转战、回身一战与新依托 |
| 闽西灯火 | 长汀、闽西、古田 | 补给、地方建设、土地政策与组织争论 |
| 再问前路 | 寻乌、永和与长沙、吉安与罗坊 | 调查、错误的代价、城市攻坚与作战方针调整 |

- **故事内容**：每关有背景、目标、场景风格、开场、节点对白、选择回应、完成后对白、收束与下一关衔接、推演失利与重试对白。
- **地图**：六张章节行程图与二十张节点图由场景数据驱动；节点类型包括剧情、整备、抉择、交战和出口。山地、村落、河流与城镇使用固定种子地形和 Mixar 场景资产组合。地图为叙事示意，不是战场精确复原。
- **人物与史料**：四名原创合成角色沈砚、罗石、田穗、阿禾串联经历。真实人物的事件放在史实旁白中，不编造其原话；各关提供对应回忆文章、核对链接与差异说明。
- **战斗节点**：可进入原有编队＋条件战术＋自动回放。兵种名称做叙事适配，数值和角色美术仍是玩法占位；当前不做历史战斗平衡。推演胜负不自动完成剧情节点，返回后通过「执行剧情目标」沿历史进程推进。会议、调查和整编关不强行插入攻城战。
- **对白播放**：默认手动继续，可开启自动播放或略过本段；略过不会跳过行动目标。精确到当前段落与台词的进度会保存。
- **行军手记**：回看已访问节点、选择回应和已完成关卡的结尾。
- **剧本与史料**：可阅读所有关卡的完整文本、人物发展、场景风格及来源，并一键导出完整 Markdown 剧本。这是含剧透的编剧阅读入口，不解锁游玩进度。
- **独立存档**：浏览器键为 `mistbound.shanhe.v1`。重新开始本篇只重置该战役，不改写 `mistbound.expedition.v2`。战术回放不保存，返回后仍停在原剧情节点。

叙事代码在 `src/narrative/`；场景内容在本 Web 项目的 `data/scenarios/shanhe-*.json`，不跨目录依赖 Godot 场景。完整开发说明见 [叙事接入说明](docs/shanhe-campaign.md)，可读剧本见 [完整关卡剧本](docs/shanhe-script.md)。场景中的音效与配乐描述是制作设定，当前演出使用文字、角色插画与三维环境，目前没有音轨或配音。

## 原创远征游玩流程

新游戏从晨星营地的大地图开始。首次抵达据点会播放剧情，读完回到队伍驻地。编队是地图上的临时操作，完成后返回打开编队的那张地图。

| 我在哪里 | 这一步做什么 | 接下来去哪里 |
| --- | --- | --- |
| 大地图 | 看队伍驻地，选择远征目的地，沿相邻道路行军 | 抵达据点后选「进入战场地图」 |
| 战场地图 | 在旧石桥或林间小径之间选路，经过高地观察点，抵达守军据点 | 选「启动战斗推演」，或先调整编队 |
| 战斗推演 | 观察行动者、技能与目标。可暂停、单步或查日志 | 播放到最后一个事件会打开战果，也可直接点「查看战果」。中途撤回需要确认 |
| 战果 | 查看胜负、回合数、双方可战人数与下一步 | 「返回战场地图」留在交战点。「返回大地图」仍驻在原据点，可向下一目标行军 |

首次取胜会解放当前据点，战果页突出「返回大地图」，方便继续行军。失利或僵持时优先提示「返回战场地图」，路线和交战位置保留，可以调整编队再战。回访已解放的据点时，复战失利也保留既有进度。全境解放后可以回访各处战场。「回看本场」读取原有事件，「调整编队再战」会按修改后的配置重新推演。

《山河初燃》沿用这两条战后出口，优先返回关卡战场地图，继续当前节点的剧情。选择返回章节大地图可以另选行程，重进本关会回到原节点。阅读剧情时也能暂返章节地图，再次进入会接着上次的台词。推演胜利后仍需在节点执行剧情行动。

## 战斗演出与回放

战斗使用 Mixar 导出的四职业模型和实时三维舞台，支持 WebGL 2。失去图形上下文时，浏览器可继续使用矢量地图与战斗回放。剑士、盾卫、弓手、牧师具有不同武器、服装和动作；敌我两侧用配色、朝向和文字标签区分。

- 顶部行动栏明确显示「行动者 → 技能 → 实际目标」、主动/被动分类、AP/PP 消耗及实际伤害/治疗量。
- 战场以行动标记、目标标记、定向轨迹、武器动作、命中效果与浮动数值展示交互。剑击、箭矢、治疗、举盾掩护、反击、追击与祈护分别呈现。
- 掩护事件先指出被保护的后排；后续攻击显示真正承伤的盾卫，并注明伤害转移。致死保留倒地形象，回看先前事件可恢复当时状态。
- 标准每事件 1.8 秒，慢速 3 秒、快速 0.9 秒。暂停冻结事件与动作进度，继续时接续剩余时长；单步、上一事件、拖动时间轴和打开「战斗日志」并点选事件支持逐次观察。手动选中的暂停事件展示清晰的动作定格。
- 每个事件的演出使用结构化的 `Frame.action`（效果类型、技能名称、实际数值、资源消耗、掩护信息），不解析日志文本。改名后的技能仍能正确显示。
- 角色动画、箭矢和特效只消费已经计算好的快照，不更改战斗状态或随机性。系统偏好“减弱动态”时保留静态连线、目标和数值信息。

## 远征工坊

标题画面的「菜单 → 内容编辑」包含角色、技能和关卡三栏。所有分类共用一份草稿，**保存后才生效**，取消不改变已保存内容。

- **角色编辑**：修改四种职业的生命、攻击、防御和速度，以及起始队员姓名、职业。
- **技能编辑**：修改主动技能名称、AP 消耗、攻击倍率、治疗量。被动技能规则固定。
- **关卡编辑**：修改三个据点的名称、副标题、故事简介，以及敌军姓名、职业、1–6 人编成与阵位。选中已占用阵位会交换两名敌军。

职业和技能数值同时作用于敌我双方，界面展示和核心结算共用同一配置。保存工坊内容会重置远征进度，让新配置从营地重新开始；页面会明确提示这一点。数值边界、职业技能匹配、唯一阵位、队伍人数与 ID 在保存时验证，非法数据不会进入战斗。

## 本地存档

配置、随行编队、战术、大地图位置、据点通关、首次抵达记录、小地图路线与位置自动保存到当前浏览器的 `localStorage`（`mistbound.expedition.v2`）。刷新后的标题页会标出上次所在地图及驻地。「继续远征」回到该地图和路段。推演期间刷新会返回交战点，已结算场次保留最近战果。旧版存档首次继续从大地图驻地开始。

存档仅对当前浏览器与网站地址有效，不同端口是不同存档。浏览器清理站点数据后会丢失。损坏存档会提示并回到初始配置；无法存储时会提示本次仅在页面内保留。「重新出发」重置远征进度，保留工坊内容。

## 确定性战斗规则

- 每轮存活角色恢复 **3 AP / 2 PP**，按速度从高到低轮流行动，最多三个行动循环、八轮。同速按唯一角色 ID 排序。无随机命中、暴击或随机伤害，同配置必得同一结果。
- 战术从上往下执行第一条合法规则：职业可用、AP 足够、条件满足、存在合法目标。没有可执行规则就跳过。生命条件检查目标生命比例，「第 2 轮起」检查当前轮数。
- 普攻默认 1 AP；破阵斩 2 AP / 1.9 倍攻击；穿透箭 2 AP / 1.65 倍且忽略防御；愈合术 1 AP / 34 HP。这些主动数值可在工坊编辑。
- 近战受存活前排阻挡，弓手可攻击后排；目标同分按阵位裁定。视觉两列是前排和后排，三条横线对应三个战术位置。
- 盾卫用 1 PP 掩护同列后排并减伤 45%；剑士存活受击后用 1 PP 反击 14；弓手用 1 PP 追击 8；牧师在攻击反应链结束后，为低于 35% HP 的存活友军用 1 PP 治疗 16。
- 被动不递归触发反击，HP 为零即阵亡。八轮后双方仍有人存活则僵持。
- 事件包含完整快照，回放不参与结算。初始四人队能赢第一场；停用全部主动战术会输，调整优先级与站位会改变过程。

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/main.tsx` | 页面流程、远征状态与保存协调 |
| `src/Landing.tsx` | 介绍页、继续/新游戏、工坊入口 |

| `src/ContentEditor.tsx` | 角色/技能/关卡草稿编辑 |
| `src/BattleView.tsx` | 编队与条件战术、单一回放计时器和播放控制 |
| `src/BattleStage.tsx` | 行动说明、目标指向、技能特效与事件快照展示 |
| `src/CharacterAvatar.tsx` | 四职业原创矢量角色与武器、施法、受击、倒地动作 |
| `src/three/` | 地形、资产实例、战斗舞台和动作播放 |
| `src/atelier/` | 资产对照、关卡布景、战斗定格与校样链接 |

| `src/core/battle.ts` | 纯战斗函数、数据类型、内容验证与默认数据 |
| `src/campaign.ts` | 存档结构、迁移和校验 |

`simulate(allies, enemies, content?)` 不依赖 React、DOM、时钟或网络。Three.js 从 `Battle.frames` 取动作、目标和伤害，动画时钟只负责呈现。

## 原创远征的当前范围

已实现完整的「大地图 → 战场地图 → 战斗推演 → 战果 → 返回战场或大地图」可玩闭环。剧情为原创的轻量分镜动画，当前世界为三个固定据点和两种局部路线；尚无自由寻路、实时世界势力模拟、任务分支、装备成长、联网、配音或正式人物美术。

## 与七日危机的边界

本目录只运行地图与战斗 Demo，不安装 DSH、不启动 NPC 服务，也不含七日危机的页面或状态。七日危机已拆到 [独立项目](../seven-day-crisis/README.md)，可分别安装和运行。

原浏览器存档键 `mistbound.expedition.v2` 与默认地址均保持不变。七日危机保留了一份战斗内核副本用于防卫结算，双方没有跨目录代码依赖；后续规则变更分别维护。
