# 《山河初燃》叙事战役接入说明

更新时间：2026-11-13。

## 范围

本战役接入 5173 的雾境远征 Web 游戏。历史范围以用户指定的「剧情动画」对话为准：1927 年夏的背景介绍，秋收起义后转向农村和山区，井冈山根据地、赣南闽西转战，至 1930 年秋罗坊会议、第一次反“围剿”前夕。根目录 Godot 战役延伸至 1931 年，与本篇是独立项目，未混用其 22 关进度。

六章二十关均具有单独地图、节点、目标和对白。人物、场景内小队任务及选择回应是原创创作。史实人物不承担作者补写的直接引语。历史失败仍然是失败；小队完成收容、撤收或联络不被描述为扭转整个战局。

## 内容与来源

- `data/scenarios/shanhe-book.json`：全篇介绍、六章目录、四名原创人物及发展线、史料边界。
- `data/scenarios/shanhe-early.json`：第 01–10 关，1927 年秋至 1928 年夏。
- `data/scenarios/shanhe-late.json`：第 11–20 关，1929 年初至 1930 年秋。
- `src/narrative/types.ts`：章节、关卡、节点、对白、选项与来源的类型契约。
- `src/narrative/book.ts`：合并内容并检查章节顺序、节点连通、对白与来源引用。
- `docs/story-skeleton-reference.md`：用户指定的对话骨架，作为创作输入留存；其中旧引用编号不充当核对来源。
- `docs/shanhe-script.md`：由场景 JSON 自动整理的完整可读剧本，包含所有选项和制作说明。

本地《星火燎原》正文作为生活细节和主题参考，不把回忆文章当成无误的逐日战史。各关 `sources` 对应 `StorySource` 的文献篇名、本地路径或公开网址，`note` 记录使用范围。发生日期差异时使用较宽时期并说明差异；不臆造未标明的篇章作者、不大量复制原文。

## 地图和流程

`StoryMap` 使用关卡节点的 `x/y` 与 `edges` 绘制节点图；`ChapterMap` 使用关卡的 `world` 坐标与章节顺序绘制行程图。坐标为百分比构图值，不是经纬度。地图上有真实地名，但并非等比例路线或地形复原。

每条边可双向行走，以便进入旁支后返回。当前节点需要先完成；出口要求所有非可选的前置节点完成。节点对白和行动结果分开记录，因此关闭或略过对白不会自动越过任务。章节结束必须读完或略过收束段落，才会解锁下一关。

选择改变原创小队的回应和手记，暂不修改历史事件、战斗数值或主线结局。选择回应在存档中通过选项 ID 保留，可回看，但完成后不能重新选择覆盖记录。

## 状态和战斗边界

`session.ts` 是纯状态转换模块。UI 只调用 `dispatchStory(book, state, command)` 并读取新状态，不原地修改模拟字典。没有额外的世界时间；对白自动播放仅切换台词，战斗计时器仅播放战斗快照。

`StorySession` 保存章节视图、当前关卡、每关当前位置/访问/已完成节点/选择、小队与待播放对白的台词序号。`decodeStorySave()` 检查版本、关卡顺序、地图可达、选择、出口条件与对白阶段，损坏存档显示提示。

战斗沿用 `BattleView`、`simulate()`、`BattleStage` 与 `CharacterAvatar`，不新增另一套数值规则。节点提供具体叙事目标；战术推演用于体验配置和回放，胜败通过可选 `onResult` 回调反馈。推演失利显示重试对白，不完成剧情目标；直接退出尚未结算的推演也不被记为失败。所有剧情结果仍经明确的节点行动命令完成。

兵种、美术和敌人是玩法占位，不对应史实兵种或参战规模。音效、配乐、环境声音保存在场景风格中供后续制作，当前未伪装为已实现的音频效果。

## 可扩展位置

新增关卡需要在内容 JSON 中补充节点、路径、开场/结束/重试对白、风格与史料，并加入章节 `levels`。增删关卡或改变节点 ID 时应同步处理旧存档迁移，不能直接依赖数组序号对应旧存档。

未来替换角色动画或接入 Phaser，可继续使用 `Battle.frames`。正式历史兵种、美术与数值可在现有战斗适配层独立推进，不必重写剧情图与存档。

## 验证

在 `living-world-web` 目录运行 `npm test`、`npm run build`；开发服务启动后运行 `npm run test:story-ui`。专项浏览器测试真实走完 20 关及其全部节点，检查旁支返回、选项、战斗失败、逐句存档恢复、原存档隔离、剧本导出和移动端布局。原有 `test:e2e`、`test:battle-ui` 用于保留原远征功能。

工作区约定的 `./scripts/test.sh` 仍从根目录执行。本次不改动 Godot 剧情、数值或地图。
